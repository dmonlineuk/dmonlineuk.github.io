# XfreeRDP Command Line

It's a challenge to get an rdp session to use all monitors, and to deliver the sound at good enough quality. I have found success with the following options:

```shell
xfreerdp3 \
    /sound:format:1,quality:2,rate:44100,latency:50 \
    /multimon \
    /kbd:layout:0x00000809 \
    /v:xxxx
```

- **/multimon** - this is what gives us full use of all monitors at full resolution.
- **/kbd:layout:0x00000809** - this ensures the keyboard layout is mapped correctly. The code being used here is for British or UK layout.
= **/v:xxxx** - this is the target, where **xxxx** can either be a machine hostname or IP address.
- **/sound:**
    - **format:1** - this enforces PCM mode.
    - **quality:2** - 0,1,2 or 10, where 0 is lowest and 2 is highest. 10 means 'server chooses'.
    - **rate:44100** - bitrate, therefore 44100 is CD quality.
    - **latency:50** - gives an amount of time for buffering. If this is too low the sound is impaired, but higher is not always desirable as it causes bad video/audio syncing.
